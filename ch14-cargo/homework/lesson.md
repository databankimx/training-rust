## Chapter 14 Homework

This chapter covered release profiles, publishing and documentation, workspaces, installing binaries, and custom Cargo commands. The exercises below practice three of
those. Each one is set up as a project for you to build in VS Code, with `cargo new`, or with a folder of your own for the workspace exercise.

1. **A documented library.** Write a small library with doc comments, examples that run as doc tests, and the `# Panics` section.
2. **A workspace.** Add a second library to a workspace, and use it from a binary.
3. **A custom command.** Write a `cargo` subcommand that counts the lines in the files it's given.

The exercises are not from the book.
