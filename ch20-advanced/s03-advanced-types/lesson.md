## 20.3 Advanced Types

Some features of the type system are used less often than the rest. This sub-section covers newtypes for type safety, type aliases, the never type `!`, and dynamically sized types with `?Sized`.

* [Newtypes, type aliases, and type safety](#goto/01-newtypes-and-aliases): units that can't be mixed, and aliases for long types.
* [The never type](#goto/02-never-type): `continue`, `panic!`, and functions that return `!`.
* [Dynamically sized types and the Sized trait](#goto/03-sized-types): `str`, pointers to it, and `?Sized`.
* [Summary](#goto/04-summary): the main ideas, and the book's quizzes.
