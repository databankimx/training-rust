## 20.5 Macros

Macros write code at compile time. This sub-section covers declarative macros, which match the source of a call against patterns, and procedural macros, which run Rust code on tokens.

* [Declarative macros](#goto/01-declarative-macros): a `my_vec!` macro, with repetition over expressions.
* [Procedural macros](#goto/02-procedural-macros): derive, attribute-like, and function-like macros, as a walkthrough.
* [Summary](#goto/03-summary): the main ideas, and the book's quizzes.
