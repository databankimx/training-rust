## Chapter 20 Homework

This chapter covered unsafe Rust, advanced traits, advanced types, function pointers and closures, and macros. The exercises below practice three of those. Each one is a project to build in VS Code with
`cargo new`. Once you've tried one, reveal its example solution in the runner, and compare.

1. **A `hashmap!` macro.** Write a declarative macro that builds a `HashMap` from `key => value` pairs.
2. **Money operators.** Write a newtype with addition, subtraction, and multiplication, and a readable display.
3. **A function pipeline.** Run a list of function pointers in order, then a list of boxed closures.

The exercises are not from the book.
