## Chapter 10 Homework

This chapter covered generic types, traits, and lifetimes. The exercises below practice all three together. Each one uses a different part of the chapter.

The exercises are not from the book.

1. **Generic stack.** Write a stack that works for any type, and a `Display` implementation that needs a trait bound.
2. **Area trait.** Define a trait with a default method, and a generic function that uses the trait as a bound.
3. **Excerpts and lifetimes.** Write a struct that holds a borrowed string, and a function that returns one of two borrowed strings.

---

### How to use these exercises

Try each one yourself before you look at the solution. The lesson gives hints. If you get stuck, the solution walkthrough is behind a **Show example (spoiler)** button, which shows the code and explains how it works.

When the compiler reports a missing trait, read the message. It usually names the trait the code needs, and that is the bound to add.
