## Chapter 3 Homework

You've reached the end of Chapter 3, which covered a lot of ground. You learned about variables and
mutability, constants and shadowing, the scalar and compound data types, functions, comments, `if`
expressions, and loops. Those are the basic building blocks of nearly every program you'll write in Rust.

The best way to make them stick is to use them on problems of your own. The three exercises below come
from the summary at the end of the chapter in *The Rust Programming Language*. Each one uses a
different mix of what you've learned.

---

### The exercises

1. **Temperature converter.** Convert temperatures between Fahrenheit and Celsius. You'll need functions,
   input, and arithmetic with decimal numbers.
2. **Fibonacci numbers.** Generate the nth Fibonacci number. You'll need a loop, a few variables, and some
   thought about how big numbers can get.
3. **The Twelve Days of Christmas.** Print the lyrics to the carol, taking advantage of the repetition in the
   song. You'll need arrays, loops, and a few functions.

---

### How to use these exercises

Each exercise has a lesson with the problem, some hints, and suggestions for extensions. Your project for
each exercise is a Cargo project, like the ones in the lessons, so you can build and run your own code with
**cargo run**, or with **F5** in the runner once you've put your code in its `src/main.rs`.

**Please try each exercise yourself before you look at the example.** Struggling with a problem is how the
ideas start to make sense. Working it out on paper, or with a small test, is worth more than reading a finished
answer. Be patient with the compiler, too. Its error messages will often show you exactly what to fix.

When you're stuck, the lesson gives you a hint. If you still can't see a way forward, the example is there.
Each exercise has a **Show example (spoiler)** button, which reveals the code and a walkthrough of how it
works. Use it to check your thinking, or to learn one way of doing things, rather than as a first move.
