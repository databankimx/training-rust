## 6.4 Ownership Inventory #1

The Ownership Inventory is a set of quizzes that check your understanding of ownership in realistic code. The programs are inspired by
common questions about Rust, and they use functions that you haven't seen before. This sub-chapter works through two of them.

* [Example: A function that returns a reference](#goto/01-returning-a-reference): a local value that a function tries to return by reference.
* [Example: A function that moves out of a reference](#goto/02-moving-out-of-a-reference): an option whose contents a function tries to take by value.
* [Lessons from the inventory](#goto/03-summary): the common thread between the two programs.
