## Chapter 13 Homework

This chapter covered closures, iterators, the improved `minigrep`, and performance. The exercises below practice closures and iterators. Each one is a small project,
which you write yourself in VS Code, starting from `cargo new`. Once you've tried one, reveal its example solution in the runner, and compare.

1. **Closures.** Write functions that return and accept closures, and sort with a closure.
2. **Iterators.** Write your own iterator, and use adapters on it.
3. **minigrep with iterators.** Add two searches that use only iterator adapters, and test them.

The exercises are not from the book.
