## Chapter 1: Getting Started

This chapter gets Rust running on your computer, and writes your first programs. You'll install the tools, print a message,
and then use Cargo, Rust's build tool, to build and run a project.

Nothing in this chapter is hard, but it's where the workflow for the rest of the course is set up. Each step builds on the last.

* [Installing Rust](#goto/01-installation): install the tools and check they work.
* [Hello, world!](#goto/02-hello-world): write, compile, and run your first program.
* [Hello, Cargo!](#goto/03-hello-cargo): use Cargo to create, build, and run a project.

---

*This overview is adapted from the Brown University edition of The Rust Programming Language.*
