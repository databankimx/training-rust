## Chapter 8 Homework

This chapter covered vectors, strings, and hash maps. The three exercises below come from the summary of Chapter 8 in the book. Each one
uses a different collection, and together they practice the ideas of the whole chapter.

1. **Median and mode.** Use a vector to find the median of a list of integers, and a hash map to find the mode.
2. **Pig Latin.** Convert words to Pig Latin, paying attention to how UTF-8 text is stored.
3. **Company directory.** Store people by department in a hash map of vectors, and list them sorted.

---

### How to use these exercises

Try each one yourself before you look at the solution. The lesson gives hints. If you get stuck, the solution walkthrough is behind
a **Show example (spoiler)** button, which shows the code and explains how it works.

When a program doesn't compile, the error usually points at the collection and the borrow that conflicts with the change you made.
