## 7.2 Defining Modules to Control Scope and Privacy

Modules group related code and control what is visible outside them. This sub-chapter shows how to declare modules, how the `pub` keyword
exposes items, and how modules form a tree rooted at `crate`.

* [Nested modules](#goto/01-nested-modules): declaring modules inside modules, and using `pub` to expose them.
* [The module tree](#goto/02-the-module-tree): parents, children, and siblings, and why modules organize code like directories.
