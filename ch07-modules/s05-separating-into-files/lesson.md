## 7.5 Separating Modules into Different Files

As a project grows, its modules can move into files of their own. The module tree stays the same, so the paths in the code don't change.
This sub-chapter shows the file layout, the rules that connect files to the tree, and a summary of the whole chapter.

* [Modules in files](#goto/01-modules-in-files): a binary split across three files, and the layout that matches the tree.
* [File paths and the module tree](#goto/02-file-paths-and-the-module-tree): one declaration per module, and the older `mod.rs` layout.
* [Summary](#goto/03-summary): the main ideas of Chapter 7.
