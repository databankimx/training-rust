## 7.1 Packages and Crates

Rust organizes code in four layers: packages, crates, modules, and paths. This sub-chapter covers the two outermost layers. A package
bundles crates, and a crate is the smallest unit the compiler considers at one time.

* [Library and binary](#goto/01-library-and-binary): a package with a library crate and a binary crate.
* [Counting crates](#goto/02-counting-crates): how the containment order works, and how to count the crates in a package.
