## Chapter 19 Homework

This chapter covered where patterns can be used, refutable and irrefutable patterns, and the pattern syntax. The exercises below each use a different part of that. Each one is a project
to build in VS Code with `cargo new`. Once you've tried one, reveal its example solution in the runner, and compare.

1. **A command parser.** Turn a line of text into a command, using slice patterns, `@` bindings, and a guard.
2. **A config reader.** Read `key=value` lines with `let...else`, and skip comments and blank lines.
3. **An expression simplifier.** Simplify a tree of expressions, using nested patterns and `|` alternatives.

The exercises are not from the book.
