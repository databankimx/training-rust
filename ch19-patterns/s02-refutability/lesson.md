## 19.2 Refutability: Whether a Pattern Might Fail to Match

A pattern is refutable if some value can fail to match it, and irrefutable if every value matches. Some places need irrefutable patterns, and `let...else` gives a way to handle a refutable
one.

* [let...else](#goto/01-let-else): a refutable pattern in a `let`, with the book's refutability quizzes.
