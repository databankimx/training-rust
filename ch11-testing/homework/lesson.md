## Chapter 11 Homework

This chapter covered writing tests, running them, and organizing them. The exercises below are for you to do in your own project, in VS Code. The runner doesn't
need to run them. Once you've tried an exercise, you can reveal the example solution in the runner, and run its tests to compare.

For each exercise, create a new project in a folder of your choice, in a terminal:

```console
cargo new exercise_name
```

Use `cargo new --lib` when the exercise asks for a library. Then write the code and tests in that project, and run them with `cargo test`.

The exercises are not from the book.

1. **Temperature.** Write a conversion function that returns a `Result`, and tests for its normal and error cases.
2. **Word counter.** Write a library with an integration test in a `tests` folder, which uses only the public functions.
3. **Leap years.** A function has a bug. Write tests that expose it, then fix it.
