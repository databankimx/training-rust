## Final Project: A Calculator

This project brings the course together. Build a calculator that reads expressions from the keyboard and prints the results. Work in VS Code, in a project of your own, using `cargo new calculator`.

Start with the core, and add the bonus items when the core works. The full requirements are in the chapter overview. Each step below lists what it covers.

The two steps are:

1. **Core calculator.** Numbers, the four operators with precedence, parentheses, unary minus, clear errors, and the REPL.
2. **Bonus items.** Exponents with `^`, `sqrt(...)`, and square and curly brackets.

Reveal an example only when you're stuck. The example is a walkthrough of one possible design, and your version can differ, as long as it meets the requirements.
